# Database Schema — Phase 1

PostgreSQL. Schema is owned by **Flyway** (`src/main/resources/db/migration`);
JPA runs with `ddl-auto: validate` so entity/DDL drift fails fast at startup.

## Conventions
- **Primary keys**: `UUID` (generated by the application via Hibernate `@UuidGenerator`).
- **Audit columns on every table**: `created_at`, `updated_at`, `created_by`,
  `updated_by`, `is_deleted`, plus `version` (optimistic locking).
- **Soft delete**: rows are flagged `is_deleted = true` rather than physically removed.
- **Timestamps**: `TIMESTAMPTZ` (UTC); `Instant` in Java.
- **Enums**: stored as `VARCHAR` with `CHECK` constraints.

## Tables

| Table | Purpose |
|-------|---------|
| `roles` | The three roles (SUPER_ADMIN, STUDENT, PARENT). Seeded by `V2`. |
| `users` | All accounts. One role per user. No public registration. |
| `cohorts` | Course intakes managed by admins. |
| `student_cohort` | Assignment of students to cohorts. |
| `parent_student` | Links a parent user to a student user. |
| `refresh_tokens` | Hashed refresh tokens (rotation + revocation). |
| `user_sessions` | Login/session audit trail. |

## Relationships
```
roles (1) ─────< (N) users
users (1 student) ─────< (N) student_cohort >───── (N) (1) cohorts
users (1 parent)  ─────< (N) parent_student >───── (1) users (student)
users (1) ─────< (N) refresh_tokens
users (1) ─────< (N) user_sessions >───── (0..1) refresh_tokens
```

## Key constraints & business rules enforced in the DB
- `uq_users_email_active` — **unique email among non-deleted users** (partial,
  case-insensitive on `LOWER(email)`), so a soft-deleted email can be reused.
- `uq_sc_student_cohort` — a student cannot be assigned to the same cohort twice.
- `uq_sc_one_active_cohort` — **a student may have at most one active cohort**
  (partial unique index on `student_id WHERE active AND NOT is_deleted`).
- `uq_ps_parent_student` — a parent/student link is unique.
- `ck_cohorts_dates` — `end_date >= start_date`.
- `ck_cohorts_max_students` — `max_students >= 0`.
- `ck_users_status`, `ck_cohorts_status` — enum value guards.
- `refresh_tokens.token_hash` unique; FK cascades on user delete.
